## Rules for using this

- News value and accuracy always come first: never pick an older, weaker or less important story because a topic scores well, and never change facts for a better hook.
- Use the patterns for choices between comparable stories, and for the title, label and the first sentence of the Short (the hook).
- Keep exploring: about one in three articles should try a topic, label type or title style that is not in the 'does well' list, so the channel keeps learning.
